Privacy

Vardis is free forever and collects nothing. This page says exactly what it reads, what it keeps, and when it talks to the internet.

What Vardis reads on your Mac

  • System and process statistics. CPU, memory, energy, disk and network counters for running apps, read through public macOS interfaces.
  • Claude Code files. The folders Claude Code uses, such as ~/.claude, to show sessions, token usage and cost. In the direct download, Vardis also reads the Claude Code sign-in from your Keychain so it can ask for your plan limits.
  • Folders you choose. For Disk Cleanup, Vardis looks at developer caches and the project folders you set. In the App Store version it sees only folders you pick.

All of this is read on your Mac and stays there.

What Vardis stores on your Mac

  • History. A local database of past readings in ~/Library/Application Support/Vardis. Older data is thinned out over time.
  • Search index. A local index of your Claude Code session text, so you can search past sessions. It lives in the same folder.
  • Settings. Your preferences, stored by macOS.

Delete that folder and the history and index are gone. Nothing is copied anywhere else.

When Vardis goes online

  1. Update check, direct download only. Vardis fetches vardis.app/appcast.xml to see if a new version exists. The request carries nothing about you or what your Mac is doing. You can turn it off in Settings. The App Store version is updated by the App Store.
  2. Your Claude plan limits. To show how much of your plan you have used, Vardis asks api.anthropic.com using your own Claude Code sign-in. Your token goes only to Anthropic, the same place Claude Code sends it.

What Vardis never collects

  • No account and no sign-up.
  • No analytics, usage tracking or telemetry.
  • No crash reports.
  • No advertising identifiers and no third-party code that reports anywhere.

There is no Vardis server. There is nowhere for your data to go.

This website

vardis.app uses no cookies, no analytics and no scripts, and loads nothing from other sites.

Check for yourself

Vardis is open source under the MIT License. You can read the code, build it yourself, or watch its network activity with any firewall app. Questions go to GitHub issues.
