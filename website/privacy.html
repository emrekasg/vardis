Privacy

Vardis is free forever and collects nothing. This page says exactly what it reads, what it keeps on your Mac, and the only two times it talks to the internet.

The short version

  • No account and no sign-up.
  • No analytics, usage tracking or telemetry.
  • No crash reports.
  • No advertising identifiers and no third-party code.
  • There is no Vardis server. There is nowhere for your data to go.

What Vardis reads on your Mac

  • System and process statistics. CPU, memory, energy, disk and network counters for running apps and processes, read through public macOS interfaces.
  • Claude Code files. The folders Claude Code uses, such as ~/.claude, ~/.claude-* and $CLAUDE_CONFIG_DIR, to show sessions, token usage and cost. In the direct download, Vardis also reads the Claude Code sign-in from your Keychain (the item Claude Code-credentials) so it can ask for your plan limits.
  • Folders for Disk Cleanup. Developer caches and the project folders you set up. In the App Store edition it only sees folders you pick.

All of this is read on your Mac and stays there.

What Vardis keeps on your Mac

  • History. A local database of past readings in ~/Library/Application Support/Vardis. Older data is thinned out over time.
  • Search index. A local index of your Claude Code session text, so you can search past sessions. It lives in the same folder.
  • Settings. Your preferences, stored by macOS.

Delete that folder and the history and index are gone. Nothing is copied anywhere else.

When Vardis goes online

Only for these two things:

  1. Checking for updates, in the direct download only. Vardis fetches https://vardis.app/appcast.xml to see whether a new version exists. The request carries the app version and the standard details any download has, and nothing about you or what your Mac is doing. You can turn it off in Settings. The App Store edition gets updates from the App Store instead.
  2. Your Claude plan limits. To show how much of your plan you have used, Vardis sends a request to api.anthropic.com with your own Claude Code sign-in. Your sign-in is sent only there, the same place Claude Code itself sends it. Anthropic's privacy policy covers that request.

Disk Cleanup never deletes

Anything you clean up is moved to the Trash, so you can put it back. Vardis does not empty the Trash for you.

This website

vardis.app is a set of static files. It sets no cookies, runs no analytics and loads nothing from other websites. Like every web host, Cloudflare, which serves these files, handles the technical details of each request in order to deliver it.
