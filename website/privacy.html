Vardis

Privacy

Vardis collects nothing. There is no account, no analytics, no crash reporting and no third-party code.

What stays on your Mac

Vardis reads system and process statistics, your Claude Code files (such as ~/.claude) and the folders you choose for Disk Cleanup. It keeps a history of readings and a search index in ~/Library/Application Support/Vardis. Delete that folder and it is gone.

When it goes online

  • Update check (direct download only): fetches https://vardis.app/appcast.xml. You can turn it off in Settings.
  • Claude plan limits: asks api.anthropic.com using your own Claude Code sign-in, the same place Claude Code sends it.

This website

Static files. No cookies, no analytics, nothing loaded from other sites.
