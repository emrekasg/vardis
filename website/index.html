The promise

Free forever. Collects nothing.

No account, no analytics, no crash reports, no third-party code. Your history, sessions and files stay on your Mac. There is no Vardis server, so there is nowhere for your data to go.

It goes online for two things only: the update check in the direct download, which you can turn off, and asking Anthropic for your own plan limits with your own sign-in.

Questions

Asked and answered.

Is it really free?

Yes, forever. There is no paid tier, no trial and no account. The code is open source under the MIT License.

When can I download it?

The first release is planned for November 2026. The download button points to the GitHub releases page, where it will appear. You can build it from source today.

Which Macs does it run on?

Any Mac on macOS 15 or later, with Apple silicon or Intel.

Will it slow my Mac down?

It is built not to. On the developer's Mac it uses about 25 MB of memory when idle, and a full sample of about 1,450 processes takes about 4 ms.

What does it record, and where?

Readings of CPU, memory, disk, network and power, grouped by app, in a local database in ~/Library/Application Support/Vardis. Older data is thinned out over time. Delete the folder and the history is gone. Nothing is copied anywhere else.

Do I need Claude Code?

No. Everything about your Mac works on its own. The Claude Code screens simply stay empty until you use it.

Does Disk Cleanup delete files?

No. It moves what you select to the Trash, so you can put anything back. Projects you used recently are protected and never offered. Docker images and containers are freed with Docker's own command.

Is Vardis made by Apple or Anthropic?

No. Vardis is an independent open-source project and is not affiliated with Apple or Anthropic.
